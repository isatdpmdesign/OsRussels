# Rubrica editorial

Pontuar de 1 a 5 apenas para comparar capítulos.

| Eixo | Pergunta operacional |
|---|---|
| Voz | A frase pertence a este POV? |
| Naturalidade | Há assimetria, banalidade e confiança no leitor? |
| Cena | Algo muda em ação, vínculo, informação ou decisão? |
| Diálogo | As falas têm desejo, desvio e consequência? |
| Interioridade | O pensamento é específico sem explicar o gesto? |
| Ritmo | Resumo e dramatização estão proporcionais? |
| Sensorial | O detalhe é concreto, seletivo e novo? |
| Romance | O avanço ou recuo foi conquistado? |
| Época | Costumes, autonomia, linguagem e objetos são plausíveis? |
| Continuidade | Timeline, informação e objetos respeitam o canon? |

## Marcas frequentes de automação

- antítese simétrica e paralelos em três tempos;
- reformulação da mesma ideia;
- frase-aforismo fechando todo parágrafo;
- “como quem”, “a forma como” e “o jeito que” em excesso;
- emoção nomeada após já ter sido mostrada;
- explicação causal depois de gesto suficiente;
- todo detalhe com significado simbólico;
- diálogos perfeitamente responsivos;
- intensidade criada só por fragmentos, itálicos e repetição.

Registrar recorrência, mas só cortar quando o recurso perdeu função.
